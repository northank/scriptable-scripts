## fng-widget.js — индекс страха и жадности

Маленький (Small) виджет с крипто-индексом Fear & Greed. Данные — [alternative.me](https://alternative.me/crypto/fear-and-greed-index/).

- текущее значение индекса, его оценка (Extreme Fear … Extreme Greed) и изменение за сутки
- цветная шкала 0–100
- мини-график за 30 дней
- значения за 1 день, 7 дней, 30 дней и среднее за 30 дней
- обратный отсчёт до следующего обновления индекса

Виджет просит iOS обновиться сразу после выхода нового значения. По тапу открывается страница индекса на alternative.me.

## rates-widget.js — курсы валют

Таблица в стиле блока курсов на главной РБК:

| Строка | Источник |
|---|---|
| EUR/RUB F, USD/RUB F | МосБиржа, вечные фьючерсы EURRUBF / USDRUBF (ISS, задержка ~15 мин) |
| CNY Бирж. | МосБиржа, CNYRUB_TOM (ISS, задержка ~15 мин) |
| EUR, USD, CNY ЦБ | Официальные курсы ЦБ РФ через [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru) |
| BTC/USD | CoinGecko (изменение за 24 ч) |

Размеры: **Large** — вся таблица со временем, **Medium** — та же таблица мельче, **Small** — 5 строк.

Параметр виджета (необязательно) — свой набор строк через запятую:

```
EUR/RUB F, CNY Бирж, EUR ЦБ, BTC/USD
```

## rub-to-eur-calc-widget.js — расчёт ₽ → ¥ → дин. → €

Сколько евро получится из рублей при цепочке обмена:

1. рубли → юани по биржевому курсу CNY (МосБиржа), комиссия 0,7 %
2. юани → динары по курсу конвертации UnionPay (RSD → CNY), комиссия 4 %
3. динары → евро по курсу продажи EUR в обменнике [funta.rs](https://funta.rs)

Размеры: **Small** — расчёт по шагам, **Medium/Large** — расчёт и использованные курсы.

Сумма, комиссии и подпись настраиваются в блоке `CALC` в начале скрипта.

Курс UnionPay: <https://www.unionpayintl.com/en/rate> (Transaction Currency — RSD, Card Currency — CNY).

## Установка

1. Установите Scriptable из App Store.
2. Создайте новый скрипт и вставьте код из файла.
3. Добавьте на домашний экран виджет Scriptable нужного размера.
4. Долгое нажатие → «Изменить виджет» → в поле **Script** выберите скрипт.

## Как работает

- Все источники запрашиваются параллельно. Если какой-то не ответил, берутся его последние сохранённые значения (кэш в Documents приложения Scriptable).
- Виджет просит iOS обновляться раз в 15 минут; фактическую частоту определяет система.
